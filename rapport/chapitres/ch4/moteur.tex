\subsection{Quelques détails qui comptent}
\begin{itemize}
  \item \textbf{Un tiret n'est pas un nom de fichier} (I1a). \cmd{X=-rf; rm \$X src} était
    autorisé : le moteur lisait \cmd{-rf} comme un fichier. Une valeur ou un résultat de
    \textit{glob} qui commence par un tiret est désormais non compris.
  \item \textbf{Lire un fichier sans se bloquer} (I1a). Un FIFO lu par \cmd{sqlite3 .read}
    bloquait le moteur au-delà de son budget, et un lien vers \cmd{/dev/zero} se lisait sans
    fin. Le moteur ne lit plus que des fichiers réguliers, en mode non bloquant, plafonnés.
  \item \textbf{Les citations ANSI-C} (W0). Un mot de commande écrit avec des échappements
    hexadécimaux (\cmd{\$'\textbackslash x72\textbackslash x6d'}, soit \cmd{rm}) était lu comme
    un outil inconnu et autorisé. Le décodage suit exactement bash~5 ; ce qu'il ne décode pas
    exactement (\cmd{\textbackslash u}, \cmd{\textbackslash c}, NUL) rend le mot non compris.
  \item \textbf{Une base SQLite est un fichier} (C2a). Elle est capturée comme un fichier du
    projet ; une base PostgreSQL ou MySQL est étiquetée \cmd{db:hôte/nom}, sans secret, et
    n'est capturable que si une URL locale littérale la désigne ; sinon, l'écriture escalade.
\end{itemize}
